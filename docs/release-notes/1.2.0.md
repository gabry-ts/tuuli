# Tuuli 1.2.0

Choosing what Tuuli shows is simpler. The Menu Bar page in Settings is now four lists, for the status item, the popover, its temperatures and its chart: drag rows into the order you like, switch off what you don't need, and add a temperature with the + row.

Right-click a mode in the sidebar to use, rename, duplicate or delete it. The same actions stay on the mode's page.

The Settings window now looks like a macOS 26 sidebar window, with the close, minimize and zoom buttons inside the sidebar. Check for Updates dims while a check is running.

Fan control works exactly as before, and the helper doesn't need to be installed again.
