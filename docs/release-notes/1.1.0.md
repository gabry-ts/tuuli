# Tuuli 1.1.0

Tuuli now shares one design with Kaiku, Kiito, Mittari and Kello. The popover, the fan curve editor, Settings, onboarding and About are built from the same components as the other apps, so buttons, switches, cards and the settings window look and behave the same everywhere.

The popover shows temperatures in a shorter form, such as 64°, next to the fan modes and a new footer with Settings, a ⋯ menu for updates and Buy Me a Coffee, and Quit. Each custom mode now has its own page in Settings, where you can use, rename, duplicate or delete it.

The Transparency slider is gone, since the background it adjusted was replaced by the system glass. The updates switch and the version moved to About.

Fan control works exactly as before, and the helper doesn't need to be installed again.
