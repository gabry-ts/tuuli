# Tuuli 1.0.0

Tuuli is now signed with a Developer ID certificate and notarized by Apple, so macOS opens it like any other app. No more Gatekeeper warnings, no more trips to Privacy & Security, and no Terminal commands to clear the quarantine flag.

Tuuli can now keep itself up to date. On the second launch it asks whether you want it to check for updates automatically, and you can change your mind at any time in Settings under General. You can also check by hand with Check for Updates… in the menu bar popover or in Settings.

The app is now a universal build that runs natively on both Apple Silicon and Intel Macs. Support for Intel Macs is experimental: sensor and fan readings there haven't been tested on real hardware yet, so feedback is very welcome.

If Tuuli is useful to you, there's now a Buy Me a Coffee… item next to Check for Updates…, and a small link in Settings.

**Updating from 0.1.x.** Earlier versions have no updater, so please download this release once by hand and replace the old app in Applications. From here on, updates arrive on their own.

**Fan control helper.** Because Tuuli is now signed by a different team, the helper installed by earlier versions will refuse to talk to the new app. Tuuli notices this on launch and offers to update the helper; it asks for your administrator password once. You can also do it later from Settings under General with Update Helper…. Until the helper is updated, macOS stays in charge of the fans. Future updates keep the installed helper working, and Tuuli will offer to refresh it the same way whenever a new version needs a newer helper.
